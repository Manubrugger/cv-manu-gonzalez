# Manú González — Portafolio

Landing one-page de CV y página de referencia del sistema de diseño personal.
Diseño y contenido definidos en `DESIGN.md` y `CV.md`; construcción en HTML, CSS y JavaScript vanilla, responsiva y accesible.

## 🌐 Páginas publicadas

- **CV (landing):** https://manubrugger.github.io/cv-manu-gonzalez/
- **Sistema de diseño:** https://manubrugger.github.io/cv-manu-gonzalez/design.html

## 📄 Documentos del repositorio

- [DESIGN.md](./DESIGN.md) — sistema de diseño: colores, tipografía, espaciado, formas y componentes.
- [CV.md](./CV.md) — arquitectura de información y contenido de la landing.
- [DESIGN.pdf](./DESIGN.pdf) — sistema de diseño (documento original).
- [Arquitectura-CV.pdf](./Arquitectura-CV.pdf) — arquitectura del CV (documento original).

## 📁 Estructura

```
├── index.html          # Landing del CV
├── design.html         # Referencia visual del sistema de diseño
├── CV.md               # Contenido y arquitectura
├── DESIGN.md           # Sistema de diseño (tokens)
├── README.md
├── assets/
│   ├── fonts/          # AsapSharp (variable, .woff2)
│   └── imagenes/       # Foto de perfil y proyectos
├── DESIGN.pdf / Arquitectura-CV.pdf
└── *.docx              # Documentos originales de trabajo
```
